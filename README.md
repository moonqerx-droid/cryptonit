# Cryptonit

Учебный симулятор торговли криптовалютой на виртуальные средства.

## О проекте

Cryptonit моделирует изменения цены криптовалюты и показывает, как решения о покупке и продаже могут повлиять на виртуальный баланс. Проект предназначен для изучения принципов торговли и связанных с ней рисков. Он не совершает реальные сделки и не является инвестиционной рекомендацией.

## Данные

В папке `data/` находятся синтетические данные, созданные для учебного анализа:

- `crypto_market_data.csv` — условная история цен за 365 дней.
- `crypto_simulation_results.csv` — результаты симуляции для 500 виртуальных участников.

Это не реальные котировки и не прогноз рынка.
